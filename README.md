# 🕷️ پنل VPN محمد مهدی احمدی

پنل کامل و شخصی‌سازی‌شده برای مدیریت سرویس VPN — ساخت کاربر، کانفیگ، لینک اشتراک، برنامه مخصوص مشتری، فیلتر سایت و مشاهده سایت‌های بازدیدشده.

────────

## ✨ امکانات

- ساخت کاربر با پروتکل‌های **VLESS / VMess / Trojan / SS / WireGuard**
- کانفیگ + QR + لینک اشتراک برای هر کاربر
- کنترل حجم مصرفی، تاریخ انقضا و تعداد اتصال همزمان
- 🚫 **فیلتر سایت** — دامنه‌های ممنوعه را تعیین کنید تا برای همه کاربران قطع شوند
- 📊 **سایت‌های بازدیدشده** — ببینید هر کاربر در VPN چه سایت‌هایی رفته
- 📱 **برنامه مشتری** در مسیر `/app` — مشتری با کد خودش وارد می‌شود و VPN را روشن/خاموش می‌کند
- پشتیبانی از ورکر کلودفلر، گروه‌بندی کاربران، ربات تلگرام و ابزارهای تست

────────

## 🚀 راه‌اندازی روی Railway (کوتاه)

۱. این کد را روی ریپازیتوری گیتهاب خودتان آپلود کنید (**پوشه‌های `static` و `worker` هم باید آپلود شوند**).

۲. وارد **railway.com** شوید ← **New Project** ← **Deploy from GitHub repo** ← ریپازیتوری خودتان را انتخاب کنید.

۳. **Deploy** را بزنید و منتظر بمانید تا لاگ `started on port 8080` را ببینید.

۴. در **Settings** سرویس ← **Networking** ← **Generate Domain** بزنید.

۵. پنل: `https://دامنه-شما/spider` — رمز پیش‌فرض `admin` است؛ **اولین کار بعد از ورود، عوض کردن رمز است**.

راهنمای کامل قدم‌به‌قدم: [`DEPLOY_RAILWAY.md`](DEPLOY_RAILWAY.md)

────────

## 📱 برنامه مشتری (برای مشتری‌های شما)

- آدرس: `https://دامنه-شما/app`
- هر کاربر یک **کد** دارد (نام کاربری یا کد اشتراک همان است که هنگام ساخت کاربر ساخته می‌شود).
- برنامه به‌صورت خودکار آدرس پنل را می‌خواند؛ اگر پنل جدید بسازید، همین برنامه بدون هیچ تغییری کار می‌کند.

────────

## 🔐 نکته امنیتی

- بعد از اولین ورود حتماً رمز پیش‌فرض `admin` را از بخش تنظیمات عوض کنید.
- برای کار کردن کامل VPN، بخش **Worker** پنل را با توکن کلودفلر تنظیم و Sync کنید.
